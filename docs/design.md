## 概要

このノートは、[requirements.md](./requirements.md) の仕様を実装するための技術構成と画面の設計書です。用語は [CONTEXT.md](../CONTEXT.md) の定義に従います。

## 技術構成

| 項目 | 採用するもの |
|---|---|
| 言語 | TypeScript |
| ビルドツール | Vite |
| UI ライブラリ | React |
| コンポーネント | shadcn/ui（トーストは Sonner） |
| CSS | Tailwind CSS v4 |
| アイコン | Lucide |
| ルーティング | TanStack Router |
| パッケージマネージャ | pnpm（単一パッケージで、workspaces と Turborepo は使わない） |
| データの保存先 | ブラウザの localStorage |
| ホスティング | Cloudflare Workers Static Assets |

- アプリはバックエンドを持ちません。アプリが扱うデータは記録と設定だけで、端末間の同期は仕様に含まれないためです。
- 技術の選び方は、利用者が別に開発している bazurecipe-search の frontend に合わせています。bazurecipe-search のパッケージマネージャは Bun ですが、このアプリでは pnpm を使います。
- 利用者は手元で `pnpm exec wrangler deploy` を実行してデプロイします。利用者は 1 人で更新の頻度も低いため、GitHub Actions によるデプロイは作りません。
- 今回は PWA（Web App Manifest と Service Worker）に対応しません。iPhone の Safari の「ホーム画面に追加」は PWA に対応しなくても使えるため、requirements.md の、ホーム画面に追加して localStorage の削除を避ける運用はそのまま有効です。

## 品質管理

- lint と format には Biome を使い、設定は bazurecipe-search の `biome.jsonc` に合わせます。
- TypeScript の設定は `@tsconfig/strictest` を継承します。
- GitHub Actions は push のたびに lint と型チェックを実行します。
- 開発者は、残量の計算、判定、1 日の区切りの処理のユニットテストを Vitest で書きます。テストケースは、実装の前に `/general-dev-skills:test-driven-design` スキルで設計します。画面の E2E テストは書きません。
- 開発者は、画面を実装した後に `web-design-guidelines` スキルで UI のコードをレビューします。

## 画面

アプリは、メイン画面（`/`）と設定画面（`/settings`）の 2 ページを持ちます。利用者はブラウザの戻る操作か、iPhone の画面左端からのスワイプで、設定画面からメイン画面に戻ります。

画面の設計は、`ui-ux-pro-max` スキルのルールに沿って決めました。括弧内の ID は、`ui-ux-pro-max` の `references/quick-reference.md` のルールの ID です。

### メイン画面

メイン画面は、上から次の順に要素を並べます。利用者が画面を開く主な場面は、15 時以降に緑茶やほうじ茶を手に取って「この 1 杯を飲んでよいか」を判断するときと、寝る前です。利用者は楽しくない画面を使い続けないため、メイン画面は数値を読む計測器ではなく、飲み物を選んでグラスに注ぐ画面にします。

1. アプリ名と設定画面へのリンク
   - 左にアプリ名、右に設定画面へのリンクを「設定」の文字とアイコンで置きます（`nav-label-icon`）。
2. 夜の窓
   - 濃藍の夜空に月と星を描いた枠です。ライトモードでも、この枠だけは夜の色にします。寝る前のカフェインを扱うアプリであることを、画面を開いた時点で伝えるためです。
   - 左に、何も飲まなかった場合の就寝時の残量を画面の中で一番大きな数字で表示し、その上に「23:00 に寝たとき、体に残るカフェイン」と説明を表示します。就寝時刻を過ぎている場合は「今すぐ寝たら、体に残るカフェイン」と表示します。
   - 数字の下に判定と、「アウトの線まで あと 37mg」または「アウトの線を 12mg 越えています」の一文を表示します。利用者が境目の値と残量を頭の中で引き算しなくて済むようにするためです。
   - 右に、今の 1 日に飲んだ分がたまる「夜のグラス」を描きます。
   - 枠の下端に、昨夜の残量と判定を左端、今の 1 日の摂取量を右端に、小さく表示します。1 日の摂取量が 400mg を超えた場合は、数字の色を変えます。
3. 飲み物の棚
   - 見出しは「次の 1 杯、どれにする？」です。
   - 7 つの飲み物ボタンを、容器の絵のカードで並べます。コーヒーの 3 つは 3 列、お茶の 4 つは 2 列にします。利用者は 15 時以降はコーヒーを飲まないと決めているため、迷う対象のお茶のカードを大きくします。ボタンの並び順は時刻や判定で変えません。目的のボタンの位置を覚えて探す時間を減らすためです。
   - ボタンの高さは 44px 以上、ボタン同士の間隔は 8px 以上にします（`touch-target-size`、`touch-spacing`）。
3. 今日の記録の一覧と取り消しボタン
   - 一覧には、今の 1 日の記録の時刻、飲み物、カフェイン量を表示します。記録の一覧は、間違えて押したときの確認に使う補助の情報なので、見出しと文字を飲み物ボタンより小さく、薄い色にします。
   - 取り消しボタンはデータを消す操作なので、飲み物ボタンから離して置き、背景を塗らない紅緋の文字のボタンにします（`destructive-emphasis`）。

画面の上端と下端には、iPhone のノッチとホームバーに重ならない余白を取ります（`safe-area-awareness`）。

### 飲み物ボタン

各ボタンは、上から次の順に表示します。

| 項目 | 表示の例 |
|---|---|
| 容器の絵 | 自宅のコーヒーはマグカップ、セブンカフェ ホット R は飲み物の色の帯を巻いた紙コップ、アイス R は氷とストローの入ったカップ、お茶の 4 つは中身の水色が見えるペットボトル |
| 飲み物の名前 | 緑茶 500mL |
| 1 杯のカフェイン量 | 65mg（推定値の飲み物は「135mg・推定値」） |
| 判定 | アウト |
| 今飲んだ場合の就寝時の残量 | 就寝時 87mg |

- 温かい飲み物の容器からは湯気が立ちます。利用者がボタンを押すと、容器が傾き、夜のグラスに注ぐ手応えを出します。
- 自宅のコーヒーの条件（豆 15g、湯 250mL）は、メイン画面のボタンには表示せず、設定画面のカフェイン量の欄に表示します。条件は値を見直すときに必要な情報で、飲むかどうかの判断には使わないためです。
- 判定は、色、アイコン、言葉の 3 つで示します（`color-not-only`）。色覚の個人差で赤と緑を区別しにくい場合があるため、アイコンの形も判定ごとに変えます（`color-guidance`）。
- 「大丈夫」は背景を塗らない藍色の文字にし、「グレー」と「アウト」だけを背景を塗ったラベルにします。午前中など、7 つすべてが大丈夫の時間帯が長く、大丈夫まで塗ると 7 つのラベルが同じ強さで並び、グレーとアウトに気付きにくくなるためです。

  | 判定 | 色 | アイコン |
  |---|---|---|
  | 大丈夫 | 藍色 `#165e83` | チェック |
  | グレー | 藍鼠 `#6c848d` | ビックリマーク |
  | アウト | 紅緋 `#e83929` | バツ |

  緑と赤の組み合わせは使いません。緑は緑茶の水色に使うためと、色覚の個人差で赤と緑を区別しにくい場合があるためです。

- ボタンの中の強弱は、容器の絵と飲み物の名前を一番強くし、判定のラベルを塗り、1 杯の量と就寝時の残量を小さく薄い文字にして付けます（`visual-hierarchy`、`weight-hierarchy`）。
- mg の数字は等幅数字で表示し、値が変わっても桁の位置がずれないようにします（`number-tabular`）。
- スクリーンリーダーには、ボタン全体を「緑茶 500mL、65mg、今飲むと就寝時 87mg、アウト」と読み上げさせます。判定のアイコンは読み上げの対象から外します（`icon-context`）。
- 時刻が進むと判定と残量が変わるため、アプリは 1 分ごとに全ボタンの表示を計算し直します。

### 記録と取り消し

記録と取り消しはどちらもトーストから元に戻せるため、アプリは確認ダイアログを出しません（`undo-support`）。

- 利用者が飲み物ボタンを押すと、ボタンは押され始めてから 100ms 以内に見た目を変えます（`press-feedback`、`tap-feedback-speed`）。アプリは確認せずに記録し、「緑茶 500mL を 16:02 に記録しました [取り消す]」のトーストを 5 秒間表示します（`success-feedback`、`toast-dismiss`）。
- 利用者が取り消しボタンを押すと、アプリは今の 1 日の最新の記録を取り消し、「緑茶 500mL（16:02）を取り消しました [元に戻す]」のトーストを 5 秒間表示します。続けて押すと、アプリは 1 つ前の記録を取り消します。
- トーストはフォーカスを奪わず、スクリーンリーダーには `aria-live="polite"` で読み上げさせます（`toast-accessibility`）。

### 設定画面

- 利用者が「保存」ボタンを押したときに、アプリは設定を保存します。入力のたびの自動保存はしません。
- 数値の入力欄は `inputmode="numeric"` にし、スマートフォンで数字のキーボードを出します（`input-type-keyboard`）。
- 判定の境目は、2 つ目の値が 1 つ目の値以上でないと保存できません。アプリはエラーを入力欄のすぐ下に表示します（`error-placement`）。
- 判定の境目の欄には「自分で決めた値」の文字と、昨夜の残量を表示します。昨夜の残量は横棒でも表示し、入力中の境目の位置と比べられるようにします。
- 判定の境目の入力欄は、「75 mg 以上でグレー」「80 mg を超えるとアウト」のように、入力欄と単位と意味を 1 つの文として並べます。
- 就寝時刻は 5:00〜翌 4:59 の範囲で受け付けます。
- 項目ごとに「初期値に戻す」ボタンを置きます。

見た目は、[anthropics/skills の frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) と [pbakaus/impeccable](https://github.com/pbakaus/impeccable) の、題材の世界から見た目を決める考え方に沿って決めました。画面の構成は、[なぜエンジニアが作る画面はダサいのか](https://qiita.com/mskmiki/items/544149987475719e417b) の 6 つの心得（表から始めない、なくても伝わるものは削る、情報に強弱を付ける、データを加工する、装飾で要素の役割を示す、設計とデザインを分けない）で見直しました。

#### 題材の世界

このアプリの題材は、利用者が毎日飲む 7 つの飲み物の液体の色と、夜に飲む 1 杯です。お茶の液体の色は「水色（すいしょく）」と呼ばれ、伊藤園が運営する [O-CHA NET](https://www.o-cha.net/jiten/nihonryokucha/sencha.html) は、煎茶の水色を黄色、ほうじ茶を茶色、紅茶を黄色からコーヒー色までと説明しています。アプリは、各飲み物にその水色に近い日本の伝統色を割り当てます。色の値は [和色大辞典（colordic）](https://www.colordic.org/w/) の値に統一します。伝統色の hex 値はサイトごとに違うためです。

| 飲み物 | 色 | 選んだ理由 |
|---|---|---|
| 自宅のコーヒー | 黒茶 `#583822` | 豆 15g で淹れるため、3 つのコーヒーで一番濃い色にする |
| セブンカフェ ホット R | 焦茶 `#6f4b3e` | 黒茶より明るくし、自宅のコーヒーと区別する |
| セブンカフェ アイス R | 枯茶 `#8d6449` | ホットよりさらに明るくし、氷で薄まった色にする |
| 緑茶 500mL | 萌黄 `#aacf53` | O-CHA NET の煎茶の水色（黄色〜緑）に近い黄緑 |
| ほうじ茶 500mL | 琥珀色 `#bf783a` | O-CHA NET のほうじ茶の水色（茶色）。紅茶より黄色寄りにする |
| ジャスミン茶 500mL | 黄金 `#e6b422` | 一次情報が見つからなかったため、緑茶と色相を離す目的で選ぶ |
| 無糖ストレート紅茶 500mL | 赤丹 `#ce5242` | 紅茶の紅色。ほうじ茶より赤寄りにする |

飲み物の色は、飲み物ボタンの容器の中身、夜のグラスの層、記録の一覧と設定画面に置く小さな湯のみの形に塗ります。ボタン全体や文字は塗りません。色だけで飲み物を見分けさせず、名前を必ず並べて表示します（`color-not-only`）。

ダークモードと夜の窓の中では、コーヒーの 3 色に白磁を混ぜて明るくします。黒茶、焦茶、枯茶のままでは、濃藍の背景の上で見えないためです。

#### 夜のグラス

夜の窓の右に置くガラスのグラスに、今の 1 日に飲んだ飲み物が、就寝時に残る量の分だけ、飲んだ順に飲み物の色の層でたまります。グラスには、グレーの境目を点線、アウトの境目を実線で引きます。利用者は、緑茶 500mL を注ぐとグラスがどこまで満ちるかを毎日見ることで、飲み物ごとの量の感覚を覚えます（requirements.md の目的の 2 つ目）。

- 一番上の層の表面は、ゆっくり波打たせ、液体が入った器に見せます。
- 利用者が飲み物を記録すると、その飲み物の層が下から満ちる動きを 1 回だけ再生します。取り消すと層が消えます。
- 夜空の星はゆっくり瞬かせます。
- OS で視差効果を減らす設定（`prefers-reduced-motion`）が有効な場合は、波、湯気、星、層が満ちる動きを再生しません。

#### 色と文字

| 用途 | ライトモード | ダークモード |
|---|---|---|
| 背景 | 白磁 `#f8fbf8` | 濃藍 `#0f2350` |
| 文字 | 墨 `#3f312b` | 白磁 `#f8fbf8` |

- 利用者は夜にアプリを開くため、アプリは OS の設定に合わせてダークモードに切り替えます。ダークモードの背景は、夜の空の色として濃藍を使います。
- 文字は Zen Maru Gothic（丸ゴシック）にし、湯のみのような柔らかさを出します。
- 1 日の摂取量が 400mg を超えた場合、数字を紅緋にします。
- `ui-ux-pro-max` のデザインシステム生成とデータベース検索は、ランディングページ向けの構成や、習慣トラッカー向けのクレイモーフィズムを返しました。このアプリは利用者が開かなくなった時点で目的を果たすアプリで、どちらも合わないため採用しません。

## データの保存

アプリは localStorage に次のデータを保存します。

| データ | 内容 |
|---|---|
| 記録 | 飲み始めた時刻、飲み物、記録した時点のカフェイン量。今の 1 日と前の 1 日の記録だけを残し、それより古い記録は削除する |
| 設定 | 就寝時刻、判定の境目の 2 つの値、各飲み物のカフェイン量 |
